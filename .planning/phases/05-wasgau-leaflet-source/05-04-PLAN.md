## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub runner -> www.wasgau.de / wasgau-dlog.1kcloud.com | Outbound HTTPS to third parties; responses are untrusted and may redirect |
| Wasgau source -> marktguru stores (shared run) | One run assembles both sources; a fault in one must not reach the other |
| diagnose workflow logs | Public Actions logs of a public repo |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-12 | Tampering / Elevation (SSRF via link or redirect) | scraper/wasgau/source.mjs createFetchText | high | mitigate | https only; request host must be in ALLOWED_HOSTS before any request (refusals not retried); res.url host re-checked after redirects; tested incl. suffix-trick hosts |
| T-05-13 | Denial of Service (oversized / decompression-bomb body, hung host) | scraper/wasgau/source.mjs | medium | mitigate | 10 s per-attempt timeout, 60 s shared deadline, MAX_BODY_CHARS 5,000,000, MAX_COLA_PAGES 8 (leaflet.mjs) |
| T-05-14 | Denial of Service on a third party (impolite load / ToS) | source.mjs + build.mjs fetchCandidates | low | mitigate | Strictly sequential awaits (tested max in-flight 1), descriptive User-Agent, Cola-pages-only downloads, one-request id cache |
| T-05-15 | Information Disclosure (bodies in errors/logs) | source.mjs error messages, index.mjs catch | medium | mitigate | Messages carry status + host only (tested: body text with "mapboxToken" never appears); only err.message is logged |
| T-05-16 | Information Disclosure (public diagnose logs) | .github/workflows/diagnose.yml | low | accept | Prints only wasgau-candidates.json (public leaflet text) plus the two public data docs; homepage HTML is never printed; read-only permissions (contents: read) unchanged |
| T-05-17 | Denial of Service (Wasgau failure blanks other stores) | scraper/index.mjs + scraper/merge.mjs | high | mitigate | Run-level tests for every failure class prove marktguru stores stay non-error and Wasgau alone degrades (D-01/D-03); the reverse direction is tested too |
| T-05-SC | Tampering | npm/pip/cargo installs | high | mitigate | No install task; no dependency added |
</threat_model>
